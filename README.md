# Firefly Jar

A tiny 2D browser game built with plain HTML, CSS and JavaScript (canvas). No build step.

## Play locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new repository and upload these files to the root (`index.html`, `style.css`, `game.js`, `README.md`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your game is live at `https://<your-username>.github.io/<repo-name>/`.

## Controls
- Arrow keys / WASD or touch-drag to move
- Space or tap to start / retry
